## Overview

`zotero-tagger` is designed to run automatically against user or group Zotero libraries, downloading attached paper PDFs, extracting key text/sections, identifying organism candidates locally, and sending structured requests to an OpenAI-compatible LLM endpoint (such as SiliconFlow) to extract standardized microbiological tags.

---

## Configuration Reference

The configuration file is located by default at `config/config.toml`. It is divided into four main sections:

### `[llm]`
- `model_name`: Model designation (e.g. `Qwen/Qwen3-8B` or `THUDM/glm-4-9b-chat`).
- `base_url`: Base URL for the OpenAI-compatible API (e.g. `https://api.siliconflow.cn/v1`).
- `temperature`: Model temperature (recommended `0.0` for deterministic structured JSON output).
- `max_input_tokens`: Maximum token budget allowed per request (text will be truncated to fit).

#### `[llm.rate_limits]`
- `requests_per_minute`: Maximum requests permitted per minute (RPM).
- `tokens_per_minute`: Maximum tokens permitted per minute (TPM).
- `requests_per_day`: Daily request budget limit (RPD).

## Zotero API Setup

1. Go to your Zotero Account Settings: **[Zotero API Keys](https://www.zotero.org/settings/keys)**.
2. Create a new Private Key with **Read/Write** permissions to your library.
3. Obtain your User ID displayed at the top of the API keys page.
4. Export them into your `.env` file:
   ```env
   ZOTERO_USER_ID=1234567
   ZOTERO_API_KEY=your_private_key_here
   ```

---

## SiliconFlow / LLM Setup

1. Sign up or log into **[SiliconFlow](https://siliconflow.cn)**.
2. Navigate to API Keys and generate an API key.
3. Set `LLM_API_KEY` in `.env`:
   ```env
   LLM_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
   ```

## Controlled Topics Customization

Under `[tagging.controlled_topics]` in `config/config.toml`, list all approved topic keywords. Any topic generated by the LLM that is not in this list will be filtered out automatically to maintain taxonomy hygiene.

## Troubleshooting

- **PDF extraction failed**: Ensure `pdftotext` is installed (`sudo apt install poppler-utils` or `apk add poppler-utils`).
- **HTTP 412 (Precondition Failed)**: Item was edited in Zotero concurrently during pipeline execution. The tagger safely skips the update.
- **HTTP 429 (Rate Limit Exceeded)**: The tool automatically respects the `Retry-After` header. Adjust `requests_per_minute` in `config/config.toml` if needed.
